pub async fn decide_with_client( &self, request: Request, client: Arc<dyn RoutedLlmClient>, ) -> Result<RoutingOutcome, RunnerError>

Routes with a host-owned client for routing-time LLM calls, such as judges.

The host owns transport, credentials, and target request settings. Configured HTTP clients, target prompts, and decision clients are not used on this path. The same algorithm instance retains its state across calls. No post-routing completion is dispatched.
