Rewrites a caller-supplied reasoning effort using the selected target’s map.

Apply this to the outgoing provider body after translation. Supported formats are openai_chat, openai_responses, anthropic_messages, and gemini_generate_content. Unknown formats, absent efforts, and efforts with no matching key leave the body unchanged. Keys are case-sensitive.
