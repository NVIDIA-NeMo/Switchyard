Struct SimpleDecision 

Source 
pub struct SimpleDecision {
    pub selected_model: String,
    pub reasoning: Option<String>,
}
Expand description

A minimal Decision implementation for one-off calls that don’t belong to a named algorithm step — judge side calls, classifier side calls, etc.

Fields§

§selected_model: String

Model or semantic target selected for the call.

§reasoning: Option<String>

Optional explanation recorded with the call.
