Struct ClientRouter 

Source 
pub struct ClientRouter { /* private fields */ }
Expand description

Resolves a routed call’s selected model to the client that serves it.

An algorithm routes among named targets; which provider each target lives on is the host’s concern, and two targets in one run may sit on different providers. A router owns that mapping and resolves the client for each kind of call.

Cloning is cheap — the mapping is shared, so one router can serve every request.

pub fn new_with_target_prompts( by_model: HashMap<ModelId, Arc<dyn RoutedLlmClient>>, target_prompts: HashMap<ModelId, String>, routing_answer_target: Option<ModelId>, ) -> Self

Build a router with target prompts used by run and decide.

routing_answer_target identifies a routing-time call whose response may become the answer. Pass None when routing only selects a later completion target. Prompt keys and routing_answer_target use the resolved model IDs stored in by_model. This constructor treats every model in by_model as a possible completion target. Use Self::new_with_completion_targets to exclude classifier-only models from the comparison of completion clients.

Source

pub fn new_with_completion_targets( by_model: HashMap<ModelId, Arc<dyn RoutedLlmClient>>, target_prompts: HashMap<ModelId, String>, routing_answer_target: Option<ModelId>, completion_targets: &[ModelId], ) -> Self

Build a router with an explicit list of models that can answer requests.

by_model contains callable LLMs, including LLM classifiers. Only the model IDs in completion_targets determine whether native Responses state needs a routing pin. Cross-format state is recorded lazily when a Responses request uses a Chat or Anthropic target. target_prompts and routing_answer_target have the same meaning as in Self::new_with_target_prompts.

A router that serves every model with one client — the single-provider case.

TranslatingLlmClient already maps model names to backends internally and rejects ones it does not know, so enumerating them here would only duplicate that.

Stop completion fallback on HTTP 429 for the given models.

For translating clients, also use TranslatingLlmClient::without_rate_limit_cooldown so later calls are not skipped with a generic cooldown error.
